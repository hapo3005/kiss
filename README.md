# KISS – Unternehmenswebsite

Unternehmenswebsite für **KISS – Keep It Simple Solutions**.

Live-Vorschau: https://hapo3005.github.io/kiss/

## Aktueller Stand

Die Website ist technisch vollständig aufgebaut und wird bei jedem Push auf `main` automatisch über GitHub Pages veröffentlicht. Sie bleibt bis zur Bestätigung der Anbieter- und Datenschutzangaben bewusst von Suchmaschinen ausgeschlossen.

Die verbindlichen letzten Freigabepunkte stehen in [`RELEASE.md`](RELEASE.md).
